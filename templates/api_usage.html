如何调用

先向管理员领取自己的 Proxy 成员 Token，每人一枚，不要共用。示意为 sk-zhangsan：姓名部分全小写、无空格；实际使用管理员发放的完整 Token。安装 Python SDK：pip install openai。

将自己的 Token 放入环境变量 ZGL_MEMBER_TOKEN 后，以 DeepSeek 为例：

import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["ZGL_MEMBER_TOKEN"],
    base_url="{{ proxy_public_base_url }}/api/llm/deepseek/v1",
)

response = client.chat.completions.create(
    model="deepseek-flash",
    messages=[
        {"role": "system", "content": "You are a helpful assistant"},
        {"role": "user", "content": "Hello"},
    ],
    stream=False,
)
print(response.choices[0].message.content)

智谱、DeepSeek 的 Coding Plan Key 若在上方领取，则按各平台官方文档直连，不使用这里的 Proxy Base URL。

Base URL 到 /v1 为止，SDK 会补上 /chat/completions。请不要把厂商 Key 或 Dashboard Token 填入示例，也不要把自己的成员 Token 提交到仓库。
