如何调用

以百炼为例：先向管理员领取 Proxy 成员 Token，放入环境变量 ZGL_MEMBER_TOKEN。它不是厂商 Key，也不是 Dashboard 专用 Token。

import os
import requests

url = "{{ proxy_public_base_url }}/api/llm/bailian/v1/chat/completions"
response = requests.post(
    url,
    headers={"Authorization": f"Bearer {os.environ['ZGL_MEMBER_TOKEN']}"},
    json={
        "model": "qwen3.6-flash",
        "messages": [{"role": "user", "content": "请用一句话介绍你自己"}],
        "stream": False,
    },
    timeout=(15, 660),
)
response.raise_for_status()
print(response.json()["choices"][0]["message"]["content"])

使用其他平台时，换成上方对应的 Base URL，并在后面加 /chat/completions；模型名称可先通过该 Base URL 的 /models 查询。不要重复追加 /v1。当前公网入口仍是 HTTP，请勿在不可信网络传输成员 Token 或敏感内容；正式使用前应启用 HTTPS。
